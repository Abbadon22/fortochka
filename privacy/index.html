Политика конфиденциальности

Сайт fortochka.synthax.ru — статическая страница. Обход блокировок и настройки живут в приложении на вашем компьютере; этот сайт только рассказывает о продукте, даёт скачать установщик и показывает каталог профилей.

Что работает без cookies

Главная страница, скачивание релизов с GitHub и просмотр каталога профилей работают без согласия на cookies. Если сервер каталога недоступен, сайт покажет сообщение об этом — остальные разделы останутся доступны.

Необязательное хранилище (по согласию)

После нажатия «Принять» в баннере cookies браузер может сохранять ответы API каталога в sessionStorage на десять минут — чтобы не нагружать сервер при повторных открытиях каталога в той же вкладке. Данные не уходят третьим лицам и удаляются при закрытии вкладки.

Форма публикации профиля

Отправка профиля идёт на API Форточки (PostgreSQL). Для защиты от ботов используется Cloudflare Turnstile — при отправке формы Cloudflare может обрабатывать технические данные по своей политике. Без согласия на cookies Turnstile на форме не загружается — опубликовать профиль можно будет после принятия баннера.

GitHub API

Страница скачивания запрашивает публичные релизы репозитория через GitHub API из вашего браузера. GitHub видит ваш IP-адрес как при обычном заходе на github.com.

Приложение Форточка

Установленное приложение не требует постоянного доступа к базе профилей: профили и обход хранятся локально. Кнопка «Опубликовать» открывает этот сайт в браузере.
